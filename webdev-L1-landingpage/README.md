# NOVA - Landing Page

## About the Project
NOVA is a modern productivity platform landing page
designed to help individuals and teams organize
their work and improve productivity.

## Technologies Used
- HTML5
- CSS3

## Features
- Responsive design
- Sticky navigation bar
- Hero section with CTA buttons
- Features section
- About section
- Contact section
- Footer with social media links

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
